# Rotunda Qwen

This project attempts to re-create the "Golden Gate Claude" paper but for the UVA Rotunda and Qwen. You can visit this site and play around with it [here](https://site-nine-lac-24.vercel.app/).

## Step 0: Steering Vectors

We attempted this with steering vectors first, which works well-ish, but it was very hard to balance between coherence and obsession. Moreover, it will sometimes just start talking about architecture/buildings in general, as we're not specific enough to extract/steer just for the UVA Rotunda.
